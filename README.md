# Mouse retinal bipolar cells with PCA

Code for a machine learning course project. We learn a low-dimensional representation of
single-cell RNA-seq counts of 19,829 mouse retinal bipolar cells with principal component
analysis, and test how well it carries over to unseen cells and to a second sequencing batch.
`analysis.ipynb` downloads the data (Shekhar et al. 2016, via the scVI data repository) and runs
the whole analysis.
